# About

This is a set of tools, small apps, templates and more for use by
Marketing Operations or Revenue Operations teams. Each folder holds
a different tool or group of tools.

## Contents

### 1. apps/peregrin

Peregrin is a lightweight React app for stakeholder request intake.
It uses an LLM to guide users, ensuring adequate information is
provided. A second LLM call then reformats the request as one or more
user stories, which are created as Asana tasks.
